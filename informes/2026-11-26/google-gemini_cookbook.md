# google-gemini/cookbook

_Repositorio muy grande: se leyó solo el README._

EN UNA LÍNEA: Es una colección de guías y ejemplos de Google para aprender a usar la Gemini API con código listo para probar.

UTILIDAD: alta

## Qué es
Hechos:
- Es un repositorio público de Google con 17 998 estrellas.
- Contiene ejemplos y guías para usar la Gemini API.
- Está organizado en guías de inicio rápido, casos prácticos y demostraciones completas en otros repositorios.
- Incluye notebooks de Google Colab para probar sin instalar nada.
- Ofrece SDK oficiales para Python, Go, Node.js, Java y C#.
- Se puede llamar a la API directamente con REST (por ejemplo, con curl) o con Postman.

Suposiciones:
- Que todo el material se puede copiar y usar directamente en proyectos propios: sin confirmar.

## Qué hay nuevo
Hechos:
- Modelos Gemini 4 (Hydrogen, Neon, Carbon y Argon) con ventana de contexto de hasta 1 millón de tokens y hasta 1 millón de tokens de salida.
- Gemini 4 Hydrogen disponible en niveles gratuito y de pago.
- Gemini 3.8 Flash para ingeniería de software y agentes autónomos.
- Gemini 3.8 TTS para generar voz de uno o varios hablantes, con diseño y clonación de voces.
- Genie 4 para mundos interactivos en tiempo real.
- Omni Flash para generar y editar video con lenguaje natural.
- Nano-Banana 2.1 para generar imágenes.
- Lyria 3.5 para generar canciones y música en tiempo real.
- Agents API con el agente "Antigravity" para crear agentes personalizados.
- Decisions API para preguntas de sí/no, opciones y puntuación con costo cero en tokens de salida.
- Webhooks para recibir notificaciones en tiempo real de tareas en segundo plano.
- Niveles de inferencia Priority y Flex.
- File Search para buscar en archivos propios en un sistema alojado.
- Grounding con Google Maps para usar datos geográficos reales.
- Gemini Transcribe para transcribir audio con marcas de tiempo y detección de hablantes.
- Live API y Live Translation para audio y video en tiempo real.

Suposiciones:
- Que todas estas funciones están disponibles de inmediato para cualquier cuenta: sin confirmar.

## Cosas útiles
Hechos:
- Notebooks de inicio rápido en Colab (autenticación, modelos básicos, TTS, Live API, entre otros).
- Ejemplos de código reutilizables: usar un navegador como herramienta, ilustrar libros, generar videos animados, graficar y mapear en vivo, entender escenas en 3D, estimar costos y monitorear la API.
