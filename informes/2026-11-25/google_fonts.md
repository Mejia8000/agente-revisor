# google/fonts

_Repositorio muy grande: se leyó solo el README._

EN UNA LÍNEA: El repositorio google/fonts guarda los archivos de letra de Google Fonts para que cualquiera los descargue y use.

## Qué es
Es un repositorio público de Google con los archivos binarios de las fuentes de Google Fonts (fonts.google.com). Tiene 20 804 estrellas. Cada carpeta de nivel superior indica una licencia. Dentro de cada familia hay archivos .ttf, un archivo METADATA.pb con datos del diseñador, categoría y licencia, y un archivo DESCRIPTION.en_us.html con la descripción en inglés de EE. UU. También incluye las carpetas /catalog, /axisregistry y /lang con metadatos adicionales.

## Qué hay nuevo
El material no menciona novedades recientes ni cambios específicos.

## Cosas útiles
- Fuentes .ttf para descargar y usar.
- Metadatos de cada familia (diseñador, género, licencia).
- Carpeta /catalog abierta a correcciones y aportes del público.
- Fontsource: paquetes NPM gratuitos para autoalojar fuentes.
- Herramienta fnt para instalar fuentes en Linux, macOS, FreeBSD y HaikuOS.
- Paquetes para sistemas RPM y DEB.
- ZIP de más de 1 GB con todas las fuentes.
- Sincronización con git para actualizar solo lo que cambia.
- No hay modelos de IA, APIs ni ejemplos de código de conector en este material.

## Avisos
- Hay que leer la licencia de cada fuente antes de usarla.
- La mayoría usan la licencia SIL Open Font License v1.1; algunas usan Apache 2 y las fuentes de Ubuntu usan Ubuntu Font License v1.0.
- Algunas fuentes tienen un "Nombre de Fuente Reservado"; si se modifican, hay que respetar ese requisito (sin confirmar cómo aplica a cada fuente en particular).
- El ZIP completo pesa más de 1 GB; el repositorio es muy grande para clonarlo sin cuidado.
- Las carpetas /axisregistry y /lang no se editan directamente aquí; los cambios van a repositorios upstream.
- Las descripciones de las familias están en inglés de Estados Unidos.
- Este repositorio no tiene código para conectar con la API de Gemini (hecho).

## ¿Sirve para sus proyectos?
- Conector a la API de Gemini en Cloudflare: No. El repositorio solo contiene archivos de fuente y metadatos, no código de API ni conectores.
- IA propia llamada Musa que entrena en Kaggle: No para entrenar. No hay modelos ni datos de entrenamiento. Solo se podría usar para mostrar texto en una interfaz, pero eso no está confirmado en el material (sin confirmar).
- Apps web publicadas con GitHub y Cloudflare: Sí. Se pueden descargar fuentes gratuitas y usarlas en esas apps, respetando la licencia de cada fuente.
